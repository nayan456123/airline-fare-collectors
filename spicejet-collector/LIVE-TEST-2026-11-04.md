## Corrections and earlier runs

The collector was corrected for connecting itineraries whose stopover code
appears later than the destination, rescheduled flights showing crossed-out
original times, the two-part no-flight notice, and airport pickers that require
an explicit option click after entering a code. Starting fares must agree with
the lowest displayed price and the reconciled airline charges.

Temporary HTTP 500/502/503/504 or recognized browser transport failures can
receive one delayed retry, with both attempts preserved. Access denials and
fare-verification failures are never retried automatically. The final batch
did not need that retry.

The original failed, cancelled and interrupted development runs remain on disk.
The initial 12-search batch had 11 successes and one rescheduled-time matching
failure. Later exploratory batches exposed a no-flight notice selector issue,
an HTTP 502 and a temporary browser internet disconnection. Those observations
led to the corrections above. Headless checks initially received HTTP 403.

After the user requested background operation, the visible batch was stopped
with 27 successful outcomes and no failures (one interrupted search and 26
skipped). Testing moved to the isolated virtual display. A controlled background
search passed before the complete background batch above.
